Kurodoko

Shade cells so that every number sees exactly that many unshaded cells.

Checkpoints

Save the board before a guess; revert to any checkpoint later.

    How to play

    • Shade some cells. Numbered cells are never shaded.
    • Shaded cells never touch side by side.
    • All unshaded cells form one connected area.
    • Each number counts the unshaded cells it can see along its row and column, itself included. Sight stops at a shaded cell or the edge.

    Controls

    • Click a cell: empty → dot → shaded → empty. Right-click or Shift-click goes backwards.
    • Hint (H) outlines in pink where to look next. If a mark is wrong, it says so; press again to see which, and again to go back to before it. Hints are counted.
    • The puzzle is finished when every cell is shaded or dotted and every rule holds. The clock starts when a puzzle is first shown (it keeps running if you leave); finishing shows the time taken.
    • The board fits the window when it can, but cells never get smaller than 20 pixels on a touch screen (14 with a mouse); a bigger board scrolls. To look closer, pinch to zoom (touch screen or trackpad).
    • Dots appear automatically (smaller) next to shaded cells and go away when the shading does; your own dots are never changed.
    • A number turns grey once every cell it sees is dotted (it plus the dots in unbroken lines from it add up to the number), and blue when it can no longer be met. Touching shaded cells and cut-off areas also turn blue.

    Puzzles

    Each day brings a new puzzle in every size from 4×4 to 60×60 (hard difficulty); a size turns green with a tick once you have solved today's. Custom makes any other puzzle. Every puzzle has exactly one solution. Easy keeps the most spare numbers, medium fewer; neither needs a what-if. Hard keeps none and needs only the occasional short what-if (try a cell, see it fail within a few steps). Fiendish may need long what-if chains. The same width, height, difficulty and seed always give the same puzzle.
